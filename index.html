Finance Dashboard UI

A minimal, high-performance web interface for managing financial data. Built with modern standards, zero dependencies (outside of dev), and designed to be easily self-hosted.

Features
  • Real-time data synchronization
  • Responsive mobile-first layout
  • Dark mode support (System preference)
